# Chemweno Top Achievers School

A responsive static website for Chemweno Top Achievers School in Kenya. The site introduces the school, highlights its academic programs, explains the admissions process, and provides contact details for prospective families.

## Features

- School branding and motto: "Knowledge is Power to Honour"
- Hero section with a school image and call to action
- About section with school information and parade imagery
- Academic overview for Lower Primary, Upper Primary, and curriculum activities
- Admissions steps and contact link
- Contact details and an inquiry form layout
- Responsive navigation and page sections for smaller screens

This project does not require a build tool or dependency installation.

1. Clone or download the repository.
2. Open `index.html` directly in a web browser.
